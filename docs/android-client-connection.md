# 客户端连接

Android 和 Linux 使用 Flutter 客户端；Windows 使用原生客户端。配对前在 Mac 启动 Companion 和后端。

## 扫码或粘贴 JSON

在 Mac 的“创建连接”生成邀请。Android 可以扫码或粘贴 JSON；Linux 可以粘贴 JSON；Windows 还支持可选摄像头和 QR 图片。二维码只是另一种输入方式。

邀请有效期 5 分钟且单次使用。连接成功后设备保存自己的凭据；重新启动通常不需要新邀请。过期、已使用、旧版共享令牌格式都需要重新配对。

首次连接用同一 Wi-Fi，检查 Mac 是否显示可用 LAN 地址。设备使用 HTTPS，默认端口 3001；不能把 `127.0.0.1:3000` 当成手机地址，也不要把代理虚拟网卡误认为可达 LAN。

公网连接需要先配置自己的 HTTPS 地址，见[外网访问](remote-access-cloudflare.md)。应用可以在可用候选间选择，并在设置中手动切换；手选线路失效后可回退。

## 成功时应看到

聊天列表能加载，实时连接可用。打开已有聊天可取历史，发送有确认结果。能取到 `/api/health` 不代表已鉴权，收到列表也不代表 WebSocket 已连通。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 邀请无效 | 在 Mac 重新生成，不重复使用已兑换的码 |
| 地址超时 | Wi-Fi 隔离、防火墙、错误网卡地址、Mac 是否休眠 |
| TLS 校验失败 | 地址和证书身份是否变化；不要关闭校验绕过 |
| 401 | 当前凭据被拒绝，重新配对；别通过反复重连掩盖撤销 |
| REST 正常但实时断开 | WSS 地址、代理 WebSocket 支持和实际鉴权日志 |
| Android 配对后无法保存 | 先查 Keystore；软件存储需明确选择，不自动回退明文 |
| 没有后台通知 | 连接与 FCM 是两条检查链，见[推送设置](setup/firebase/README.md) |

发送显示等待确认时不要连续重发。设备丢失时在 Companion 撤销它。当前协议与安全边界见[连接规则](features/connection.md)。
